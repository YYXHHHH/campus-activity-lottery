## 5. 设计与实现的偏差与经验

实现期发现并处理了 12 项与《开发文档》的差异（详见《实现说明》§4），其中值得记录的经验：

1. **枚举 `str()` 陷阱**：`class ActivityStatus(str, Enum)` 下 `str(member)` 返回 `"ActivityStatus.DRAFT"`，导致聚合键与响应文案错位；以 `_StrEnum` 覆写 `__str__` 解决。
2. **递补前须 `flush()`**：「退出 + 递补」同事务内先置 WITHDRAWN 再统计，依赖 autoflush 时序会算错差额；显式 `db.flush()` 保证正确性。
3. **事务边界纪律**：`promote_waitlist` 只 `flush()` 不 `commit()`，提交权归调用方，避免嵌套事务破坏「退出+递补」原子性。
4. **开放文档前缀**：Swagger 挂 `/api/docs`，避免与静态站点根路径冲突。

## 6. 已知限制与改进方向

| 限制 | 影响 | 改进方向 |
| --- | --- | --- |
| 单进程单 worker | 多实例会导致调度器重复触发 | 分布式锁或独立定时服务 |
| SQLite 写并发上限 | 高峰依赖 WAL + 重试 | 切 MySQL |
| 静态二维码可被截图代签 | 冒名签到风险 | 30s 轮换动态码 + 人工核对 |
| 统计实时计算无缓存 | 千行级无压力 | 物化视图/缓存 |
| 前端无构建、无路由框架 | 靠 query 参数传 id | 迁移 Vue 3 + Vite |
| `audit_logs` 埋点表未建 | 审计依赖 INFO 日志 | 按需补建 |
