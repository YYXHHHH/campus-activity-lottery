# 校园活动报名抽签与签到系统 —— 用户操作手册

> **所属阶段**：部署运维（使用说明）　|　**版本**：v1.0　|　**整理日期**：2026-10-02
> **内容来源**：《需求与设计文档》§2、§10、附录；`README.md`；《开发文档》§2 M10。
> **适用读者**：学生、组织者、管理员等最终用户。

## 1. 系统简介

本系统面向校园活动，提供「发布活动 → 学生报名 → 截止自动抽签 → 候补递补 → 二维码签到 → 统计导出」的完整闭环。系统分三种角色：学生（STUDENT）、组织者（ORGANIZER）、管理员（ADMIN）。

服务默认地址：`http://localhost:8000`（部署方式见《部署运行手册》）。

## 2. 访问与默认账号

首次运行 `seed.py` 会生成以下演示账号：

| 角色 | 用户名 | 密码 | 说明 |
| --- | --- | --- | --- |
| 管理员 | `admin` | `admin123` | 可管理用户角色与启用状态 |
| 组织者 | `org1` | `123456` | 拥有 3 个演示活动 |
| 学生 | `stu001`~`stu020` | `123456` | 每个活动 20 条报名 |

> 首次使用请先在 `/register.html` 注册，或使用上述演示账号登录。

页面入口：

| 页面 | 地址 | 角色 |
| --- | --- | --- |
| 登录 / 注册 | `/login.html`、`/register.html` | 公开 |
| 活动列表 | `/index.html` | 全部 |
| 活动详情与报名 | `/activity_detail.html?id=<id>` | 学生 |
| 我的报名（含二维码） | `/my_registrations.html` | 学生 |
| 创建活动 | `/organizer.html` | 组织者/管理员 |

| 签到台 | `/checkin.html` | 组织者本人/管理员 |
| 用户管理 | `/admin.html` | 管理员 |

## 3. 学生操作

1. **注册/登录**：打开 `/register.html`，填写用户名（4–50 位字母/数字/下划线）、密码（≥ 6 位）、姓名，选择角色「学生」；或在 `/login.html` 用演示账号登录。
2. **浏览活动**：在 `/index.html` 查看「报名中 / 已抽签」的活动，支持关键词搜索、状态筛选与分页。
3. **报名**：进入活动详情页，勾选「是否接受候补」后点击报名。报名成功后状态为「待抽签」。
4. **取消/退出**：截止前可在「我的报名」取消；抽签后中签者可主动退出，退出后二维码立即失效，名额由候补自动递补。
5. **查看结果与二维码**：在 `/my_registrations.html` 查看状态、抽签序号、签到状态；中签后点击「查看二维码」获取签到码（仅中签状态可见）。
6. **现场签到**：向组织者出示二维码，由组织者扫码/输入完成签到。

状态含义：待抽签、已中签、候补中、未中签、已取消、已退出。

## 4. 组织者操作

1. **创建活动**（`/organizer.html`）：填写名称、地点、开始时间、**报名截止时间**、**名额**（≥ 1），可选描述与结束时间；可保存为草稿或直接发布。
2. **活动管理**（`/activity_manage.html?id=<id>`）：
   - **报名名单**：按状态查看全部报名；
   - **中签名单**：查看中签者与候补队列；
   - **签到名单**：已签到 / 未签到分组；
   - **统计**：报名、中签、候补、未中签、退出、签到人数与中签率、签到率、名额使用率；
   - **导出**：下载「报名表」或「中签表」Excel（文件名含活动名与日期）。
3. **抽签**：报名截止后系统每 30 秒自动扫描并抽签（详情页为兜底）。也可在管理页点击「立即抽签」手动触发；抽签幂等，重复触发不改变名单。
4. **签到**（`/checkin.html`）：组织者输入/粘贴/扫码获得签到码提交；页面实时显示「已签到 X / 中签 Y（签到率 Z%）」；重复签到会提示首次签到时间；可按学号手动补签。
5. **名额调整**：在截止前可调大名额，系统会自动从候补队列按抽签序号递补；调小名额不得低于当前中签人数。

## 5. 管理员操作

1. 打开 `/admin.html`，查看用户列表（支持关键词与角色筛选、分页）。
2. 可修改用户角色、启用/禁用用户；禁用后该用户旧 token 立即失效。
3. 管理员拥有组织者的全部权限，并可管理所有活动（不受归属限制）。

## 6. 常见问题

- **二维码扫码打不开**：`.env` 中的 `PUBLIC_BASE_URL` 仍是 `http://localhost:8000`，手机无法访问本机；改为局域网 IP 后重启服务。
- **报名提示已截止**：报名截止后不再接受报名，请在截止前完成。
- **抽签没出结果**：确认活动已到截止时间、服务为单进程单 worker；详情页会自动兜底触发。
- **签到提示已签到**：同一签到码不可重复签到，提示中会给出首次签到时间。
- **摄像头扫码按钮不显示**：局域网 `http://IP:8000` 属非安全上下文，浏览器禁用摄像头；请改用「输入/粘贴签到码」。
